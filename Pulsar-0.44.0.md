## Lo más destacado

- **Mira lo que cambió un agente.** **⌃⌘C** da la vuelta al panel de un agente y te enseña sus **cambios**: la lista de archivos y el diff de cada uno, en unificado o lado a lado. Elige entre lo que aún está **sin confirmar** y **todo lo de la rama** frente a su base. Pulsar solo mira: no hace commits ni toca el repositorio, y el agente sigue trabajando igual. Desde ahí puedes abrir el archivo en tu editor en esa línea o copiar su ruta. También está en el «⋯» del panel.

## A tener en cuenta

- _Paneles_ · «Cambios» lee con el Git de Xcode o de las Command Line Tools. Un repositorio con **filtros obligatorios** (por ejemplo, Git LFS con archivos modificados) no se puede comparar: Pulsar lo dice en vez de ejecutar esos programas.

## Mejoras

- _Seguridad_ · Mientras «Cambios» tapa una terminal, lo que escribas, pegues o sueltes **no llega al agente** a ciegas.

## Arreglos

- _Agentes_ · Los relevos ya no se quedan parados por «configuración cambiada» cuando Claude Code cambia de modelo o esfuerzo o actualiza un plugin por su cuenta.

## Highlights

- **See what an agent changed.** **⌃⌘C** flips an agent's pane to show its **changes**: the list of files and each one's diff, unified or side by side. Choose between what's still **uncommitted** and **everything on the branch** against its base. Pulsar only looks: it makes no commits and doesn't touch the repository, and the agent keeps working as usual. From there you can open the file in your editor at that line or copy its path. It's also in the pane's “⋯” menu.

## Good to know

- _Panes_ · “Changes” reads with the Git from Xcode or the Command Line Tools. A repository with **required filters** (for example, Git LFS with modified files) can't be compared: Pulsar says so instead of running those programs.

## Improvements

- _Security_ · While “Changes” covers a terminal, what you type, paste or drop **doesn't reach the agent** blindly.

## Fixes

- _Agents_ · Handoffs no longer stall on “configuration changed” when Claude Code switches model or effort, or updates a plugin on its own.
