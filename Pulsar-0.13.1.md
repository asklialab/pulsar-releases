## Lo más destacado

- **Recuperación automática del refresco de las terminales.** Si el sistema deja de enviar fotogramas a una terminal, Pulsar activa un **refresco de respaldo** para que vuelvas a ver lo que escribes, la salida del agente y el desplazamiento, **sin reiniciar la sesión**. Corrige una causa de congelación intermitente que también puede afectar a las terminales de Claude Code.

## Arreglos

- _Paneles_ · Una terminal que acaba de quedar oculta **conserva su pausa** aunque termine de montarse su vista; vuelve a refrescarse al mostrarla.

---

## Highlights

- **Automatic recovery when terminal refresh stalls.** If the system stops delivering frames to a terminal, Pulsar activates a **fallback refresh** so you can see what you type, agent output and scrolling again, **without restarting the session**. This fixes one cause of intermittent freezing that can also affect Claude Code terminals.

## Fixes

- _Panes_ · A terminal that has just been hidden **stays paused** even if its view finishes mounting; it resumes refreshing when shown.
